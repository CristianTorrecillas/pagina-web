Panel de la página

Desde acá editás los textos, subís fotos y publicás los cambios en tu página.

Primera vez: crear tu llave de GitHub (token)
  1. Tocá Crear el token en GitHub. Se abre GitHub con casi todo completado.
  2. En Repository access elegí Only select repositories y marcá pagina-web.
  3. Revisá que en Permissions → Repository permissions diga Contents: Read and write.
  4. Tocá Generate token, copiá el código (empieza con github_pat_) y pegalo acá abajo.

Crear el token en GitHub

El token queda guardado solo en este navegador y sirve únicamente para tu repositorio. No lo compartas: con él se puede cambiar la página. Dura un año; cuando venza, creás otro igual.
